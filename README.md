# Newsletter Studio

A personal system for writing a thoughtful email newsletter: capture ideas, write issues in a consistent format, export them as email-ready HTML, and learn from every send.

## Run it

```bash
npm install
npm run dev
```

## What's inside

| Tab | What it does |
|---|---|
| ✍️ **Write** | Issue composer with the fixed format (subject, preview, opening, big idea, learning, links, question), live desktop/phone email preview, editing checklist, and one-click copy as email / HTML / Markdown / text |
| 🌱 **Ideas** | Idea inbox with a Seed → Sprouting → Ready → Published pipeline, tagged by content pillar. "Write issue" turns an idea into a draft |
| 📈 **Log** | Log opens, clicks, replies and unsubscribes per issue, see rates and when the next issue is due, and keep a "one lesson" per issue |
| 📖 **Playbook** | The full framework (`framework/PLAYBOOK.md`) and launch templates (`framework/launch-invite.md`) |
| ⚙️ **Foundation** | Name, sender, *why*, sign-off, cadence, pillars, accent color, and backup export/import |

Data is stored in your browser's localStorage. Use **Foundation → Export backup** regularly.

## Sending

Write in the studio, click **Copy email**, and paste into your email platform's editor (Kit, Beehiiv, Buttondown, Substack, or Gmail for tiny lists). See the Playbook, section 6.
